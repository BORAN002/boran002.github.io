内容分类阅读方式反馈

这里记录学习、实践和论文阅读，重点是值得保留的 Insight，以及可以复用的 Method。内容按主题持续扩展，Agent 是其中一份主题笔记。

内容分类

  • Note：持续更新的主题笔记。先解释概念如何工作，再结合例子记录 Insight 与 Method。例如 Agent 中的 Context Engineering。
  • Blog：围绕一次实践或一个问题展开的完整文章，包括项目复盘、实验记录和观点分析。写清问题、过程、结果与局限。
  • Paper：单篇论文阅读与专题整理。保留原论文链接，区分论文提出的结论、阅读中的判断和已经验证的结果。目前收录 Agent Tool Use 文献专题，可通过 Explorer 检索 359 篇论文。
  • About：本站的内容范围、分类与阅读说明。

阅读方式

关键术语使用英文。Note 中的 Basic 说明机制与必要背景，Insight 记录值得注意的进展、设计判断及其适用条件。Paper 中的 Method 尽量展开为可理解的步骤，并附上来源和阅读范围。

主题笔记会在原文中持续修订；论文阅读不等同于实验复现。引用中的数字和结论应结合原始来源、任务条件与评测设置理解。

反馈

如有错误、失效链接或值得补充的资料，可以在 GitHub Issues 留下对应页面和来源。

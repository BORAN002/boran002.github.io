GardenDesigner: Encoding Aesthetic Principles into Jiangnan Garden Construction via a Chain of Agents

代码 / 软件 / 科研执行 · 扩展相关 · 方法 / 系统

Idea

GardenDesigner 把江南园林的审美与文化规则编码到四个顺序协作的 agents：地形、道路、选材、布局。系统将文字要求转成 procedural modeling 参数，再用园林知识检索和几何约束生成场景，配合 GardenVerse 资产库与 Unity 交互工具支持非专业用户创建和编辑园林。

Research Problem

通用 landscape generators 更重视几何覆盖或通行效率，容易产生离散水面、过直道路和文化风格不一致的布置。江南园林要求以水组织紧凑空间、沿曲径逐步显露景观，并协调建筑、植物和山石的象征意义。普通 LLM 与通用 3D asset 数据缺少这些领域知识。

Insight

审美原则可拆成不同层次的可执行决策：整体地形决定道路，道路和区域语境约束选材，资产知识再决定相对布局。将文化关系显式写入检索描述和空间 constraints，可减少模型凭通用场景先验排列对象的偏差，让语言设计意图落到可搜索的结构参数。

Method

  1. Terrain Distribution Agent 把用户文字与全局原则映射到地形存在性、数量、覆盖率和单区域面积参数，在 Outside/Waterbody/Land/Ground 的 2D grid 上运行 genetic algorithm，使用 water-centric fitness 引导演化。
  2. Road Generation Agent 根据地形和用户需求确定入口、keypoints、道路宽度与复杂度，对 grid boundaries 评分，兼顾可达覆盖、沿边界布局以及避免过直或过度弯折，再生成 smooth splines。
  3. Asset Selection Agent 将 GardenVerse 中的 expert-annotated garden knowledge 编码进 vector store，结合区域信息检索建筑、植物和山石，输出各区域资产集合。
  4. Layout Optimization Agent 使用 edge/middle、around/backed-up、near/far、aligned、face-to 等八类关系，构造五组位置与方向 losses。先确定 main/anchor objects，再用 depth-first search 寻找其余对象的有效位置和旋转。

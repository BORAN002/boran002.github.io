A Survey of Large Language Model-Based Search Agents

Idea

这篇 survey 用 How to Search、How to Optimize、How to Apply、How to Evaluate 四个问题整理 LLM-based Search Agents，将检索组织方式、训练方法、应用环境与评测口径放进统一 taxonomy。其产出是研究地图和开放问题，而不是一个新 agent 或可复现的训练 pipeline。

Research Problem

Search Agent、Agentic RAG 与 Deep Research 的工作快速增长，不同论文混合比较 search structure、model tuning 和工具环境，使读者难以定位贡献。Survey 试图澄清动态 information seeking 的核心设计维度，并指出现有评价过于关注最终答案、忽略证据处理和来源可靠性的问题。

Insight

论文观察到，tuning-free 系统常把探索能力外显为 tree/graph workflows，tuned models 则可把部分策略内化到 sequential decisions；这种分类帮助理解相近效果背后的成本与控制位置差异。它也将 reasoning-centric scaling 与 search-centric scaling 区分，强调更多 internal tokens 和更多 external interactions 是不同资源。

Method

  1. 按 search structure 对既有方法分类：Parallel 预先拆分多个 queries，Sequential 根据结果与 reflection 决定下一步，Hybrid 以 tree 或 graph 结合分支探索、依赖关系与回溯。
  2. 按 optimization 分为 tuning-free 的 single/multi-agent workflows、test-time scaling，以及 tuning-based 的 SFT、RL 和混合策略；进一步整理 reward 中的 correctness、format、efficiency、diversity、evidence quality 等目标。
  3. 将 evaluation 拆成任务与 judging 两层：closed/open-ended QA、fact-checking、domain tasks 使用不同指标，rule-based、LLM-as-a-Judge、Agent-as-a-Judge 和 human checks 则有不同能力与成本。
  4. 从 taxonomy 汇总未来方向：融合 web、private databases 与内部 memory，处理不完整或冲突证据，发展 multimodal retrieval、long-horizon RL 与更稳定的执行基础设施；这些属于综述归纳与研究建议，并非已由本论文实验验证的解决方案。

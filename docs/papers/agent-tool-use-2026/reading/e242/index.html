LLM-Based Multi-Agent Systems for Clinical Workflows: A Survey of AI Hospitals

领域应用 / 数据分析 · 扩展相关 · 综述

Idea

这篇 Survey 用 workflow state transition 组织 AI hospitals 研究：agent 不仅回答医学问题，还需承担明确 role、传递 shared state、关联 evidence、使用 tools，并在 safety gates 下推进或 escalation。论文据此建立设计 taxonomy、四层 evaluation stack 与 Integration Readiness Levels，讨论什么证据能够支持更强的 autonomy。

Research Problem

医疗 multi-agent 论文常按角色数量、模型模块或最终 QA accuracy 比较，但真实 workflow 的失效可能发生在 handoff、记录更新、API 调用或责任交接中。静态 benchmark 的提升无法直接说明系统能否保持跨步骤证据与可追溯性。Survey 研究如何界定 AI hospital、描述设计差异，以及把评估结果转化为可检查的 readiness evidence。

Insight

多 agent 的价值需要落在可观察的 workflow 行为上，例如 handoff 是否完整、引用能否追溯到 record、何时将不确定案例交给人。更强 retrieval 或 long-context 能力只有改变这些指标才支持集成主张。论文明确将 simulation、真实数据 replay 与 deployment evidence 分开；所提 IRL thresholds 是需要按场景调整的 protocol defaults，不是通用认证标准。

Method

  1. Scope 与 taxonomy：把具有 persistent state、跨 role handoff、grounded tools、safety gates 和 audit traces 的系统纳入 AI hospital 范围；按 Roles & Handoffs、Memory/Evidence/Tools、Reasoning/Control/Escalation 组织设计空间。
  2. Workflow mapping：以 triage → consultation → discharge 为贯穿示例，逐阶段记录谁负责、哪些 state/evidence 必须传递，以及什么 gate 可以阻止或升级下一步，避免只比较独立模块。
  3. Evaluation stack：联合检查 safety、process、outcome 与 operations；将模型能力映射到 citation coverage、handoff completeness、escalation、tool failure、latency 等 observable，并为不同 integration tasks 指定必要 logs。
  4. Readiness framework：IRL1–IRL6 从 sandbox、shadow replay、有限 human-in-the-loop pilot 逐步走向受监控 rollout，配套 autonomy ceiling 与证据要求；再用 longitudinal drift、capacity-blind planning 等 failure modes 组织研究议程。这里的 Method 是综述分析框架，没有声称训练一个新临床 agent。

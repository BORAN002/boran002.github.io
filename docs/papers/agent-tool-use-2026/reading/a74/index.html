GCA Framework: A GCC Countries–Grounded Dataset and Agentic Pipeline for Climate Decision Support

领域应用 / 数据分析 · 直接工具使用 · 方法 / 系统

官方论文页 ↗PDF ↗文献检索
IdeaResearch ProblemInsightMethodSources

Idea

GCA 将 Gulf Cooperation Council 六国的气候知识、时序环境图和可调用工具组织为统一 dataset 与 agentic pipeline，让回答既能引用地区政策背景，也能查询空气质量、遥感或天气等具体信息。其核心贡献是构建地区化数据与工具使用训练、评估链路，而不只是给通用模型加入一个气候角色提示。

Research Problem

通用 climate QA 对 Gulf 地区政策、城市和环境特征覆盖不足，通常也缺少把文本、时序图像与实时外部工具结合的训练信号。即使模型知道气候概念，也可能选错工具、参数或单位，无法支持具体城市和时间范围内的决策问题。

Insight

地区知识 grounding 与工具执行正确性是两个互补瓶颈。保留来源、时间、地点和单位，可以把生成问答及工具返回与可追溯证据关联；将 tool selection、arguments 和 answer synthesis 分别评估，则能定位最终答案之外的流程错误。

Method

  1. 构建约 20 万条 GCA-DS，覆盖 Bahrain、Kuwait、Oman、Qatar、Saudi Arabia、UAE。文本流程从政府政策、机构报告、研究与新闻检索，保留 URL 等 provenance，去重后按 512-token chunk、384-token stride 提取有来源指针的 atomic facts，再生成多种问答。
  2. 视觉流程读取 ERA5、CAMS、GloFAS 等环境数据，对城市坐标取网格数据，统一单位、时间和缺失值处理；从历史数据形成非重叠 90 天窗口、标准化图表与元信息，生成异常、比较、预测和插补等问题。
  3. 以 Qwen2.5-VL-7B 做 LoRA instruction fine-tuning，混合文本、视觉与工具调用样例。工具覆盖遥感土地、生物多样性、网页、碳、空气质量以及天气气候水文六类，并统一 typed calls 与返回格式。
  4. 控制器识别意图、选择必要工具、验证 schema 和单位、按依赖串联调用，最后结合地点、时间与返回证据作答；benchmark 分别统计 instruction、tool、argument、summary 和最终答案正确性。

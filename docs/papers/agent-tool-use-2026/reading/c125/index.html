Simple Agents Outperform Experts in Biomedical Imaging Workflow Optimization

Idea

论文系统研究 coding agents 如何为固定 biomedical imaging tools 自动生成 preprocessing/postprocessing functions，用少量标注验证集优化已有生产流程。核心不是提出更复杂的多角色架构，而是从简单 code-execution feedback loop 出发，逐项分析模型、专家示例、记忆和 AutoML 的实际价值。

Research Problem

实验室间显微镜、染色和分辨率变化使生产模型在新数据上失效，重训需要大量标注，人工适配又耗时。已有科学 agents 多关注任务编排或研究发现，缺少针对工具适配的受控设计研究。更强 reasoning、function memory 或更大 API lists 是否稳定有益，不能仅凭通用 agent 经验判断。

Insight

适配难度可拆成 API composition space 与 parameter space：有的任务只需少数固定操作但参数很敏感，有的允许广泛操作组合。专家函数可能帮助找到特殊参数，也可能限制组合探索。复杂组件的收益由任务空间决定，执行反馈支持的简单循环已经能搜索出有效代码。

Method

  1. Base Agent 接收 task prompt、数据特性与 API 信息，Coding Agent 每轮生成三个前后处理函数对，Execution Agent 嵌入固定模型流程运行，返回错误及验证分数，连续 20 轮。
  2. 以 Polaris 单分子检测、Cellpose 细胞分割、MedSAM 皮肤镜分割为三个 case studies，分别优化 F1、AP@IoU 0.5 和 NSD+DSC，对照原作者生产代码中的专家函数。
  3. 逐项加入 expert functions、保存高低分函数的 function bank、更换 GPT-4.1/o3/Llama 模型，或每五轮触发 AutoML 参数搜索。每种配置运行 20 个 seeds，并分析 API 共现、函数多样性、代码长度与参数分布。
  4. 作者从全部 runs 按 validation scores 选 top 15 functions，再报告其中最高 test score。进一步通过参数手动校正及降低 AutoML 频率/预算分析偏差与过拟合，发现复杂组件的收益随任务变化。

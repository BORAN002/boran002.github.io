DRAMA: Next-Gen Dynamic Orchestration for Resilient Multi-Agent Ecosystems in Flux

工具调用 / 训练 / 评测 · 扩展相关 · 方法 / 系统

官方论文页 ↗PDF ↗文献检索
IdeaResearch ProblemInsightMethodSources

Idea

DRAMA 为成员随时加入、退出或恢复的 embodied multi-agent systems 提供动态任务编排。Strategic Layer 计算 agent-task affinity 并分配任务，Collective Intelligence Layer 汇总空间经验预测对象位置，Autonomous Layer 让每个 agent 同时执行任务并监测同伴，通过 trust-chain 实现故障接管。

Research Problem

静态角色与固定任务分配在 agent dropout、负载变化或新任务到达时容易留下无人执行的目标。即使有周期性重新分配，也可能无法及时响应故障。分布式探索若缺少共享对象位置经验，会重复搜索并进一步降低吞吐，单靠增加 agent 数量不能解决调度与连续性问题。

Insight

任务分配、共享空间知识和局部故障恢复应联动。位置预测决定谁更适合执行，执行过程产生的新观察反过来改进预测；预先建立有序备援关系则使故障发生时无需完全重新协商。将 executor 与 guardian 双重职责下放，可在全局协调之外保留局部恢复能力。

Method

  1. 汇总各 agent 的对象-位置 observations，训练 MLP predictor 估计给定 room/context 下的 object-location distribution，以期望位置或最可能位置作为任务空间先验。
  2. Affinity 用可用 workload capacity 的正项和到预测任务位置距离的负项组成。Dual-Capacity Hungarian Assignment 将每个真实 agent 展开为两个 virtual slots，再求 assignment 并合并，使一个 agent 最多持有两项任务。
  3. 对每项任务建立按 affinity 排列的 guardian chain，primary executor 位于链首，后继监测前驱状态。故障后由下一 guardian 接管未完成任务，并重新校准负载与 affinity。
  4. Autonomous Layer 保留关键子任务详细 memory、压缩近期次要历史，完成感知、细化计划和动作执行，同时通过 heartbeat/status monitoring 检测异常。在扩展 VirtualHome-Social 场景中分析动态成员、任务冲突、运行效率与鲁棒性。

FinSight: Towards Real-World Financial Deep Research

Idea

FinSight用Code Agent with Variable Memory将财务数据、工具和其他agents共同放入可编程变量空间，让financial deep research通过实际数据操作与递归协作产出多模态报告。系统先生成带证据和图表的Chain-of-Analysis，再编排完整报告，并用视觉反馈迭代修正绘图代码。

Research Problem

通用deep research通常围绕网页文本搜索和单次写作，难以可靠计算异构财务表格，也容易缺乏分析深度、专业图表与一致引用。把大量原始数据反复塞进文本context会浪费空间并增加数值推理错误；固定的数据收集到写作流水线又难以在分析中发现缺口后补取材料。

Insight

金融研究的关键对象可以保持为DataFrame等执行对象，由模型查看元数据后按需调用和运算，而无需把全部状态转成自然语言。把分析与叙事分开可先建立可追溯的分析片段，再围绕outline复用证据；图表实际渲染后的问题也可通过VLM反馈进入代码修订回路。

Method

  1. 构建包含data、tool与agent三类对象的统一变量空间。各agent读取变量元数据、生成reasoning及Python action，经解释器执行更新状态；Data Collection、Data Analysis和Report Generation拥有不同工具与数据权限，可调用Deep Search补足信息。
  2. 收集API表格、网页及PDF信息后，Data Analysis并行处理多个分析视角，生成CoA segments；引用先以自然语言source placeholders产生，再用BM25匹配数据元信息并设阈值筛除低可信匹配。
  3. 分析agent生成图表描述、数据和绘图代码，执行后交VLM检查标签、颜色等视觉问题并迭代修改；为图表生成caption，用embedding retrieval把正文中的import描述匹配到已生成的图像。
  4. Report Generation先拟outline，再逐节检索相关数据和CoA，沿用第一阶段建立的引用和图表标识写出报告；在10个公司、10个行业研究目标上，以券商长报告作为参照，通过事实、分析价值和呈现方面的指标及人工评价比较系统。

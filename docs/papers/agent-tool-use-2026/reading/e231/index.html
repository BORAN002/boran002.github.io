C-World: A Computer Use Agent Environment Creator

GUI / Web / Computer Use · 扩展相关 · 方法 / 系统

官方论文页 ↗PDF ↗文献检索
IdeaResearch ProblemInsightMethodSources

Idea

C-World提供可按需创建computer-use环境的系统，将工具动作空间、任务分布、状态转移和reward四个部分组合起来，并支持真实API与World Engine模拟两种运行方式。其重点是批量生成带长程依赖及复杂约束的跨应用任务，让同一环境同时供应能力评估和训练轨迹。

Research Problem

现有agent环境常由人工围绕少数领域定制，扩展新工具、任务与异常情况成本高；只测试单轮function calling或schema遵从也不能反映长期执行和恢复能力。全依赖live API虽真实，却受费用、限流和服务漂移制约，难以持续生成大量交互数据。

Insight

环境可拆成相对独立的接口层、任务生成层、状态控制层与评分层，而工具schema和类别共性为模拟转移提供先验。受控干预可重复触发恢复问题；约束密集的任务则让评测聚焦跨步骤协调，而不只是发出语法正确的tool call。

Method

  1. 从MCP registry及人工补充整理276 servers、204应用的5571个工具，验证认证可用、调用成功及返回可用；以server、名称、description和schema签名建立BGE-M3/FAISS索引，通过search_tools按需发现工具。
  2. 采样1–3个seed tools，检索相近工具并跨server均衡组包；LLM生成统一目标任务，再循环检查tool coverage及constraint quality并修订。query做模糊化改写以降低工具名keyword shortcut。
  3. 以运行时State Controller截获调用和观察，按预设策略注入tool故障、状态漂移及任务约束变化；真实模式执行live服务，模拟模式用类别card、schema、few-shot和session log生成保持上下文一致的响应。
  4. 组合日志可验证的schema、顺序及来源多样性评分，与三模型majority-vote的完成度、grounding等语义评分；使用同backbone的Planner分解并监控sub-goal graph，Actor按ReAct发现和调用工具，生成评测及后续训练轨迹。

AeroAgent: A Vision-Physics-Decision Framework for Aerodynamic Vehicle Design

多模态感知与创作 · 直接工具使用 · 方法 / 系统

官方论文页 ↗PDF ↗文献检索
IdeaResearch ProblemInsightMethodSources

Idea

AeroAgent 将 text / image-to-3D、aerodynamic surrogate 与 design planner 接成 propose–evaluate–refine loop。所有模块围绕统一、可编辑的 vehicle surface representation 工作，在有限 high-fidelity CFD budget 内筛选同时满足外形意图与 aerodynamic requirements 的候选。

Research Problem

生成漂亮的 3D vehicle 不代表能完成工程设计：shape edits 必须同时满足尺寸、style 与 drag 约束，而逐个候选运行 high-fidelity CFD 成本高。不同模块若使用不一致的 geometry representation，还会增加 normalization、编辑和 physics evaluation 的衔接误差。

Insight

快速探索与最终确认可以采用不同 fidelity：用 geometry-aware surrogate 支持大量 inner-loop edits，只把收敛后的少量 top candidates 交给 CFD。将 constraints 写成明确的 feasibility tests，并记录 mesh transformations，可使自然语言设计要求进入可追踪的优化流程；surrogate prediction 仍需最终确认。

Method

  1. Vision module 解析 design intent、规范图像输入，使用 image-to-3D 生成 STL，并执行 axis alignment、unit normalization、mesh-health checks 和 class-specific size projection；局部修改采用受步长约束的 free-form deformation。
  2. AeroFormer 分别编码 surface 与 volumetric points，以 geometry-conditioned cross attention 连接两类表示；通过对应 regression objectives 预测 pressure、velocity 或 drag，训练监督来自 CFD 数据。
  3. Decision module 根据 size、用户要求的 drag threshold 和 aesthetics predicates 检查 feasibility，结合 prototype priors 与 physics feedback 选择 windscreen、roof、tail 等可执行 edits。
  4. 循环用 surrogate 评估新候选，在收敛、无可行改进或 budget / time limit 时停止；仅对最终 top-K 设计运行 high-fidelity CFD，并保存 geometry edits、预测与配置日志。

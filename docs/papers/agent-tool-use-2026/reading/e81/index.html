ZARA: Training-Free Motion Time-Series Reasoning via Evidence-Grounded LLM Agents

工具调用 / 训练 / 评测 · 直接工具使用 · 方法 / 系统

官方论文页 ↗PDF ↗文献检索

Idea

ZARA 把运动传感器序列转为可解释统计证据，由 LLM agents 逐步挑特征、排除活动并作最终判断。它分离静态的 activity-pair feature-importance knowledge 与随用户/传感器位置变化的局部检索证据，以冻结 encoder 和 LLM 支持无需在线参数适配的 HAR。

Research Problem

固定分类器适应新用户、硬件或类别通常需要重新训练，直接把长数值序列或曲线图交给 LLM 又有 token 成本和 grounding 问题。一般 RAG 返回相似窗口，但未说明哪些物理特征真正区分候选活动，也易让多数类覆盖长尾候选。

Insight

候选活动间的可区分物理属性与当前部署下这些属性的分布是两种不同知识。前者指导应测什么，后者给出当前 query 与各类的实际对照；分阶段缩小候选再重新选细粒度特征，使自然语言结论能指向明确统计量和参考窗口。

Method

  1. 离线从 labelled motion windows 提取均值、方差、RMS、频域和跨通道统计；对活动对使用 AutoGluon 与 permutation feature ranking，经交叉验证聚合 importance，存成可查询 feature registry。
  2. 按身体佩戴位置建立 vector stores，以冻结 Mantis 编码器生成归一化 embeddings，FAISS 检索；数据同时保存 labels、统计特征和 sensor metadata。
  3. 对每个候选活动分别检索参考窗口，多传感器按同步样本索引用 Reciprocal Rank Fusion 融合，保证每个假设都有局部证据。
  4. Feature Selector 先依全候选知识选粗特征，Evidence Pruning 比较 query 与各类 mean±std 剔除不匹配活动，再针对剩余候选选更细特征，Decision Insight 输出 label 与统计依据。
  5. 采用 subject hold-out，知识库与索引只来自 seen subjects；较多类别场景可先取最相关十类，再进行层级推理，并以跨数据集设置检验迁移。

From Intuition to Investigation: A Tool-Augmented Reasoning MLLM Framework for Generalizable Face Anti-Spoofing

工具调用 / 训练 / 评测 · 直接工具使用 · 方法 / 系统

官方论文页 ↗PDF ↗文献检索
IdeaResearch ProblemInsightMethodSources

Idea

TAR-FAS 将 Face Anti-Spoofing 从直观的二分类或简短描述，改成 Chain-of-Thought with Visual Tools：先形成初始判断，再按需检查纹理、频率、边缘或局部区域，最后给出 Real / Spoof 结论。ToolFAS-16K 与三阶段训练让普通 MLLM 学习工具辅助调查。

Research Problem

跨数据域的攻击材料和成像条件变化，使传统 classifier 难泛化；简单语义描述主要捕捉面罩轮廓等明显线索，难利用高质量打印或屏幕回放的微弱频谱、纹理证据。通用 MLLM 对工具变换图的解读也不一定可靠，直接生成推理标注可能产生错误证据。

Insight

已有 FAS 专用视觉算子把不同伪造痕迹转成互补观察，而 expert classifiers 可以为轨迹标注提供工具结果参考。训练时保留快速分类能力，同时让最终正确性约束多样工具探索，能够把已有领域知识与按需深入检查结合。

Method

  1. 从 CelebA-Spoof 取 16,172 张 real 与十类 spoof 图像，配置 Zoom-In、LBP、FFT、Wavelet、Laplacian edge 和 HOG 工具，分别暴露局部、纹理、频域及结构线索。
  2. Gemini-2.5-Pro 生成最多六轮 reasoning–tool / reasoning–answer 轨迹。标注时提供类别提示，工具专属轻量 binary expert 给出 spoof probability；检查最终标签、调用格式及分析逻辑，并排除泄漏 hint 或 expert confidence 的文本。
  3. 先用普通 FAS 描述监督传递领域知识，再用 ToolFAS-16K 注入多轮协议；对首轮分类 loss 加权，避免学习长轨迹时丢失基础分类能力。
  4. DT-GRPO 对同题采样轨迹，组合 fast classification、最终 reasoning 分类及工具多样性 reward；两类答案均受格式约束，工具 reward 只在最终判断正确时生效。以单一 CelebA-Spoof 训练、十一目标域测试，使用 HTER 和 AUC 检验泛化。

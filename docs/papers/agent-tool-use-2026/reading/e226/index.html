Paper Circle: An Open-source Multi-agent Research Discovery and Analysis Framework

搜索 / 检索 / Deep Research · 直接工具使用 · 方法 / 系统

官方论文页 ↗PDF ↗文献检索
IdeaResearch ProblemInsightMethodSources

Idea

Paper Circle 将文献发现和单篇深读整合为共享状态的多 agent 平台：Discovery Pipeline 持续更新候选论文与排序，Analysis Pipeline 把 PDF 内容转成有 provenance 的 typed knowledge graph，支持 graph-aware Q&A、覆盖检查和结构化 review。主要贡献是可复用的研究工作流与产物组织。

Research Problem

检索工具找到论文后，研究者仍需解析方法、实验、图表和关系，并在阅读列表、摘要、引用与分析输出之间保持一致。单体聊天缺少可追踪中间状态，纯 chunk retrieval 又难关联某个方法与其图表、实验或定义，也难发现静默遗漏的章节。

Insight

检索与理解需要不同的 agent 职责，但应共享清晰的数据状态和来源信息。用 section/concept/method/experiment 等类型及 relations 组织单篇内容，可以在语义相似检索之外保留结构依赖；覆盖检查则补充“答得像正确”之外的文档完整性信号。

Method

  1. 基于 smolagents 的 CodeAgent orchestrator 协调 ToolCallingAgents；Discovery 分别解析 intent/年份/会议/模式、执行 offline/online search 与去重、按 BM25/semantic/recency/citation 或 reranker 排序，并更新 shared state、统计和同步 exports。
  2. 用 PyMuPDF 提取 metadata、hierarchical sections、figures/tables/equations 及上下文，按段落结构分块，保留视觉元素的独立 chunk；图中节点和边记录 source chunk IDs、页码、verification status 与 confidence。
  3. Concept、Method、Experiment 与 Linkage extractors 分阶段构造 MindGraph；Q&A 联合 vector retrieval 与一跳 graph expansion，返回带来源的答案，locate 定位原文；CoverageChecker 统计图、表、章节和公式覆盖并指出遗漏。
  4. 扩展 Deep Analyzer、Critic、Literature Expert、Contribution Analyzer、Reproducibility Checker 等 review roles，由 orchestrator 汇总报告。检索实验以 50 个合成自然语言 queries 比较模型、retrieval settings 与 agent compositions，记录 Hit、MRR、Recall、耗时和逐步状态。

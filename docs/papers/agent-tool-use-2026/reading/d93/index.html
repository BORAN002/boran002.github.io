FlowSearch: Advancing Deep Research with Dynamic Structured Knowledge Flow

搜索 / 检索 / Deep Research · 直接工具使用 · 方法 / 系统

官方论文页 ↗PDF ↗文献检索
IdeaResearch ProblemInsightMethodSources

Idea

FlowSearch 以可持续修改的 Dynamic Structured Knowledge Flow 组织 deep research。它将 search、solve、answer 子任务及依赖显式表示为 DAG，让独立分支并行收集证据，同时根据中间发现增删或修改节点和依赖，以协调探索广度与局部推理深度。

Research Problem

单 agent 的长上下文容易锁定早期假设，多 agent 固定串行计划又需要压缩跨步骤上下文，导致推理链断裂。研究任务的证据依赖往往非线性且会随新发现变化，因此预先一次性规划或简单按位置传递结果难以适应未知知识缺口。

Insight

把依赖关系和已获得知识从线性对话中显式化，使执行顺序由证据就绪状态决定，而非固定脚本。局部 executor 可深入处理节点，refiner 则结合全局知识修订研究结构；两层配合提供系统的任务组织方式，但一致性仍由 LLM 检查判断。

Method

  1. 每个节点记录任务类型、描述、执行状态和知识 context，边记录结果如何支持或约束下游；从唯一 query node 出发，planner 反复展开子问题及 supporting evidence，直到不再添加节点。
  2. Knowledge Collector 选择全部依赖已完成的可执行节点，分配带 browsing、download、VQA 等工具的 executor，各自开展序列推理与检索，可并行处理独立分支。
  3. 成功节点把获取或推导的信息压缩成 context 供下游读取，失败则更新状态；每轮执行后交给 Knowledge Flow Refiner 检查事实冲突与规划不足。
  4. refiner 可 Add/Delete/Modify Node 和 Edge，修正任务内容、缺失证据与错误依赖，再继续 collect–refine loop。
  5. 最终 query node 针对简短问题整合相连证据直接作答，复杂报告则汇总全图知识；在 GAIA、GPQA、HLE 与科学研究任务检验框架表现。

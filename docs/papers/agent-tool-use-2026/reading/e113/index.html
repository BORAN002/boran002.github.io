Mem2Evolve: Towards Self-Evolving Agents via Co-Evolutionary Capability Expansion and Experience Distillation

规划 / 记忆 / 工作流 · 直接工具使用 · 方法 / 系统

官方论文页 ↗PDF ↗文献检索
IdeaResearch ProblemInsightMethodSources

Idea

Mem²Evolve 联合演化 Asset Memory 与 Experience Memory：前者存工具和专家代理，后者存成功策略、失败教训与实现经验。解决任务时优先复用已有资产，能力不足时用经验引导创建；任务结束再验证资产、提炼经验，形成能力扩展与经验积累的双向循环。

Research Problem

仅积累经验的代理仍受静态工具边界限制，无法获得缺失功能；只会临时生成新工具或专家的系统又容易每次从零开始，重复同类错误并留下不可复用成功。新资产是否可靠也不能仅凭一次任务最终答对来判定。

Insight

经验不仅能指导执行，还能降低新能力生成和调试的试错成本；新工具和专家反过来创造新的执行场景与经验。将“可执行资产”和“为什么成功/失败的策略知识”分别组织、相互检索，比把它们混为原始历史更便于持续复用。

Method

  1. Asset Memory 维护 Agent Bank 的角色、专长、行为建议与工具集合，以及 Tool Bank 的 MCP 兼容实现和输入输出文档；Experience Memory 按 title、适用情境、use cases、content 保存 agent/tool lessons。
  2. Forward inference 先分解子任务，按相似度阈值招募专家与 top-k 工具；无匹配能力时结合任务、相关工具经验和 web 信息生成新工具，或按任务需求创建专家代理。
  3. 专家在检索到的经验指导下以 ReAct 执行，各子任务结果汇总为答案；LLM judge 读取任务、轨迹和答案，输出成功判断与 critique，默认不依赖 ground-truth labels。
  4. Backward evolution 对新资产生成并执行 critique-driven tests，失败则修订与重测，通过后入库；同时从成功轨迹抽象策略与使用模式，从失败和大量调试中提取 anti-patterns 与 failure-fix pairs，更新经验记忆。

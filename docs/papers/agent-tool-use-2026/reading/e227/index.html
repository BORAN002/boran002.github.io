BioProAgent: Neuro-Symbolic Grounding for Constrained Scientific Planning

Idea

BioProAgent 把科学协议生成改为由 deterministic finite-state machine 约束的 neuro-symbolic planning：LLM 负责提出科学步骤和修订方案，显式状态、操作权限及物理规则决定何时可以推进。系统同时用符号引用压缩大型设备定义和中间产物，使长协议规划不必反复把完整 JSON 塞进上下文。

Research Problem

面向 wet-lab automation 的一般 LLM agent 容易在多轮规划中遗忘约束、混淆草案与可执行代码，面对大型 instrument schema 又会发生 context saturation。单靠自然语言自我检查，无法确保离心速度、温度等设备限制始终有效；一旦错误进入真实实验，后续执行往往不可逆。

Insight

科学合理性与物理可执行性需要不同检查机制：前者依赖领域推理，后者可由设备注册表上的确定性规则验证。把它们变成状态迁移条件，可以让失败触发有针对性的修复，而不是继续生成。符号化 working memory 则保留完整工件的可访问性，同时降低决策提示中的信息负担。

Method

  1. 建立 hybrid cognitive memory：working memory 用键保存完整工件，仅向模型投影键和语义预览；执行时再解析符号为真实参数。episodic memory 保存状态、动作和约束信号，long-term memory 按需检索领域知识。
  2. 用 FSM 表达 DESIGN、VERIFY、RECTIFY 等认知阶段，并维护草案、代码及 scientific/physical verification 的状态。优先级矩阵先处理物理失败，再处理科学失败；不同状态只开放相应设计、检查或修复工具。
  3. Scientific Reflector 检查实验逻辑与 controls；Physical Rule Engine 对照包含 22 类仪器的 registry 检查每个操作的可执行约束。只有代码生成且物理验证通过时才允许进入执行阶段，否则 interlock 引导修复。
  4. 在扩展 BioProBench 上分别评估草案、代码、长程协议和故障注入；长程集含 9 个协议、547 个步骤，以状态控制、记忆和验证模块的实验比较检验稳定性。
